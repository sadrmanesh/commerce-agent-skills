# معرفی فارسی

**commerce-agent-skills** مجموعه ای متن باز از مهارت ها و قانون ها برای ایجنت های برنامه نویسی است که روی فروشگاه های اینترنتی و مارکت پلیس ها کار می کنند. هدف این است که ایجنت در کارهای حساس تجارت الکترونیک، مثل پرداخت، وب هوک سفارش، مدل داده محصول و جستجو، همان قراردادهای درستی را رعایت کند که یک مهندس باتجربه رعایت می کند.

## چه چیزی داخل آن است

- **مهارت ها:** هر مهارت یک پوشه با فایل SKILL.md در قالب باز Agent Skills است که یک روند مرحله به مرحله، نام دقیق APIها و حالت های مهم را توضیح می دهد.
- **قانون ها:** برای هر مهارت یک قانون کوتاه Markdown وجود دارد که می تواند همیشه در کانتکست ایجنت بماند.
- **آزمون ها:** هر مهارت چند تمرین ارزیابی دارد که مشخص می کند پاسخ درست چه چیزهایی باید داشته باشد و چه چیزهایی نباید داشته باشد. این بررسی ها در CI اجرا می شوند.
- **اجرای ارزیابی:** اسکریپت run-evals.mjs پاسخ های ایجنت شما را با همین تمرین ها مقایسه می کند و برای هر مهارت امتیاز می دهد.
- **نصب با npx:** بسته `@sadrmanesh/commerce-agent-skills` روی npm منتشر شده است. یک دستور بدون وابستگی که مهارت ها و قانون ها را فهرست می کند و در پروژه شما کپی می کند و بعد از دانلود بسته به اینترنت نیازی ندارد.

## دسته بندی مهارت ها

- **پلتفرم ها و فروشگاه ها:** ووکامرس، وردپرس، Shopify و فروشگاه headless با Next.js
- **پرداخت و سفارش:** درگاه پرداخت، Stripe، درگاه های ایرانی مثل زرین پال، وب هوک ها، اشتراک، ریسک و تقلب، مالیات و ارسال، تسویه با فروشندگان
- **کاتالوگ و جستجو:** مدل داده محصول، رتبه بندی جستجو، جستجوی برداری، فید Merchant Center و متن محصول بدون ادعای نادرست
- **تبدیل و رشد:** تجربه پرداخت، دسترس پذیری فروشگاه، سرعت و Core Web Vitals، داده ساختاریافته برای سئو، رویدادهای تحلیلی و بومی سازی فارسی و راست به چپ
- **عملیات فروشگاه:** موجودی در چند انبار، مرجوعی و بازپرداخت، قیمت گذاری عمده فروشی، ورود و انتقال کاتالوگ و ابزارهای MCP برای فروشگاه

## شروع سریع

</div>

```bash
npx @sadrmanesh/commerce-agent-skills init
```

<div dir="rtl" markdown>

این دستور را در ریشه پروژه اجرا کنید. همه مهارت ها در پوشه `.agents/skills` و همه قانون ها در پوشه `.agents/rules` کپی می شوند. اگر فقط چند مهارت لازم دارید یا ایجنت شما پوشه دیگری را می خواند، از این دستورها استفاده کنید:

</div>

```bash
npx @sadrmanesh/commerce-agent-skills list
npx @sadrmanesh/commerce-agent-skills add rtl-and-persian-localization iranian-payment-gateways
npx @sadrmanesh/commerce-agent-skills init --layout root
npx @sadrmanesh/commerce-agent-skills init --skills-dir path/to/skills --rules-dir path/to/rules
```

<div dir="rtl" markdown>

گزینه `--no-rules` فقط مهارت ها را کپی می کند، `--force` مهارت های نصب شده را جایگزین می کند و `--dry-run` فقط نشان می دهد چه فایل هایی نوشته خواهند شد.
